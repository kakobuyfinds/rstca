How to use the SuperBuy spreadsheet

  1. Save the exact variant. Open the CAFANS listing and record the source link, color, size and current price. Check that your agent accepts the underlying seller link before paying.
  2. Compare measurements. For clothing, compare chest width and garment length with something you own. For shoes, check which sizing system the seller uses and ask for an insole measurement if the fit is unclear.
  3. Review warehouse photos. Check the size label, color and any visible defects. If details are unclear, ask whether extra photos are available and check the exchange window before forwarding.
  4. Compare shipping quotes. Use the same destination and parcel details for each quote. Check whether the carrier bills by actual or volumetric weight and include any fees in your budget.

SuperBuy spreadsheet FAQ

What is a SuperBuy spreadsheet?

It is a product shortlist for comparing listings before ordering with a shopping agent. A useful shortlist includes links, variants, prices and any measurements you still need to confirm.

Where do the listings come from?

This independent guide displays a selection from the public CAFANS catalog. The product links and both main buttons lead to CAFANS.

Do the catalog prices include shipping?

Each displayed amount is an estimated product price. Use your agent’s current quote for domestic delivery, international shipping and other charges.
